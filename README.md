# Besin Cetveli

React + Tailwind CSS ile geliştirilmiş günlük beslenme takip uygulaması.

## 🚀 Özellikler

- ✅ **Besin Kaydı**: Besin adı, ölçek (100 gram, 100 ml, 1 adet), protein ve kalori girişi
- ✅ **Günlük Takip**: Seçili güne ait toplam protein ve kalori hesaplaması
- ✅ **CRUD İşlemleri**: Besin ekleme, düzenleme ve silme
- ✅ **Local Storage**: Veriler tarayıcıda kalıcı olarak saklanır
- ✅ **Responsive Tasarım**: Mobil ve masaüstü uyumlu
- ✅ **Türkçe Arayüz**: Kullanıcı dostu Türkçe arayüz

## 🛠️ Teknoloji Stack

- **Frontend**: React.js 18.3.1
- **Styling**: Tailwind CSS 3.4.4
- **Build Tool**: Vite 5.4.1
- **Package Manager**: npm

## 📦 Kurulum ve Çalıştırma

1. **Bağımlılıkları yükleyin:**
   ```bash
   npm install
   ```

2. **Geliştirme sunucusunu başlatın:**
   ```bash
   npm run dev
   ```

3. **Tarayıcıda açın:** `http://localhost:5173`

## 📱 Kullanım

1. **Besin Ekleme**: Üst formdan besin adı, ölçek, protein ve kalori bilgilerini girin
2. **Gün Seçimi**: Sağ panelden takip etmek istediğiniz tarihi seçin
3. **Günlük Özet**: Seçili güne ait toplam protein ve kalori miktarını görün
4. **Düzenleme/Silme**: Listedeki besinleri düzenleyin veya silin

## 🎯 Proje Amacı

Bu proje, staj eğitimi sırasında geliştirilmiş bir beslenme takip uygulamasıdır. Kullanıcıların günlük besin tüketimlerini takip etmelerine ve protein-kalori dengelerini izlemelerine yardımcı olur.
